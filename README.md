# Pokédex — estudo de consumo de API

Projeto de interface web para consultar informações de Pokémon utilizando a PokéAPI.

## Funcionalidades

- Busca e visualização de Pokémon.
- Consulta de informações adicionais, como atributos, tipos e evolução, a partir da API pública.
- Navegação para uma página de detalhes.

## Tecnologias

- HTML
- CSS
- JavaScript
- Fetch API
- [PokéAPI](https://pokeapi.co/)

## Estrutura

```text
Projeto-Pokedex/
├── index.html
├── pokemon-detail.html
└── assets/
    ├── css/
    ├── img/
    └── js/
```

## Como executar

Na raiz do projeto, execute um servidor HTTP local:

```bash
npx serve .
```

Abra o endereço exibido no terminal. A visualização de dados depende de acesso à PokéAPI.

## Objetivo

Praticar JavaScript, requisições HTTP e atualização dinâmica do DOM. É um projeto de estudo não afiliado à Nintendo, Game Freak ou The Pokémon Company.
